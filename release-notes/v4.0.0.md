A full rewrite of TP Auto Clicker: a faster, more accurate clicker, a new screen-watching automation engine, and a new compact design.

## Download

Download `TPAutoClicker.exe` below and put it in its own folder. No Python is needed. On first run, it creates `templates/`, `sequences/` and `settings.json` next to itself. Windows SmartScreen may warn because the exe isn't signed; click *More info → Run anyway*.

## What's new

### Clicker
- Precise timing: an interval in milliseconds, with Slow/Med/Fast/Max presets and a live clicks-per-second readout.
- Random variation (0–50%), so clicks aren't perfectly regular.
- Clicks wherever the cursor is, or at a fixed spot that you pick on screen.
- Stops after N clicks or N seconds. You can also hold a key while clicking and set a start delay.
- Anti-AFK nudges the mouse every so often.
- Stopping is instant, even with long intervals.

### Automation (new)
- Watches the screen with image matching and runs a sequence of steps: wait for an image, click an image, click a spot, press a key, wait, or check a pixel colour.
- Comes with a ready-made loop for the tower defense game. It waits for the end-of-level popup, clicks **RETRY**, turns on **2X** speed and clicks **START**, then repeats.
- Works for every level result (LEVEL CLEARED, THE BASE DROWNED, …), because it looks for the RETRY button instead of the popup title.
- Works at other screen resolutions (positions are scaled from 1920×1080).
- A built-in step editor lets you capture new button images from your screen.
- Failsafe: move the mouse into the top-left corner of the screen to stop.

### Design
- A compact pro-tool look: charcoal panels, small type, and an icon sidebar for Clicker, Automation, Log and Settings.
- Dark is the default. Light, System and accent colours are in *Settings → Appearance*.
- Mini controls float on top of other windows (and the game), so you can start and stop without switching windows.
- The layout scales cleanly: nothing gets cut off on narrow windows or stretched on wide ones.

### Hotkeys
- **F6** starts/stops the clicker, **F7** starts/stops the automation and **F8** stops everything. You can change these in Settings.

### Other
- Settings from v3 are carried over.
- Settings, templates and sequences live next to the exe, so a shortcut or another folder still finds them.
- *Settings → Check for updates* checks this Releases page.
